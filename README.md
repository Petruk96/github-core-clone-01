A lightweight GitHub-compatible forge featuring Git Smart HTTP, REST v3, GraphQL, and MCP. Built for the make.fun GitHub-compatible git forge bounty.

## Run it

Requires Node.js 22.18.0 or later.

```sh
npm start
```

The Make.fun harness provides `MAKEFUN_ENV_URL` and drives the server lifecycle. Run `npm start` inside that environment.
